# Security Policy 🔒 (HYDRA-UMC-ANDROID-CONTROL)

## Reporting a Vulnerability

Security in the Android app focuses on **Keystore-backed encryption** and **Biometric bypasses**.

1. **Report**: Email `electrohobby3d@gmail.com`.
2. **Scope**: Credentials stored in `EncryptedSharedPreferences` and Bluetooth permissions.
3. **Safety**: Any flaw that allows an app overlay to hijack the E-STOP button is a high-priority issue.
